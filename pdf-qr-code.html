PDF QR codes can be used on business cards, brochures, posters, product packaging, menus, educational materials, event documents, invoices, manuals and marketing materials.

Important

PDF QR Code FAQ

What is a PDF QR code?

A PDF QR code is a QR code containing a web link to a PDF document. When scanned, the QR code can open the PDF URL on a compatible device.

Is the PDF QR code free?

Yes. AuraQR provides this PDF QR code generator for free.

Does AuraQR host my PDF?

No. AuraQR only generates the QR code from the PDF URL you provide. Your PDF remains hosted at its original location.

Can I download the generated QR code?

Yes. After generating the QR code, use the Download QR Code button to save it as a PNG image.

Will the QR code expire?

The QR code itself does not have an expiration date. However, the QR code will only work as long as the PDF URL remains accessible.
