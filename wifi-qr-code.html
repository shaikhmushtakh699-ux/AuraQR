WiFi QR Code FAQ

What is a WiFi QR code?

A WiFi QR code contains the information needed for a compatible device to connect to a wireless network without manually typing the network name and password.

How do I create a WiFi QR code?

Enter your WiFi network name, password and security type above, then click Generate WiFi QR Code.

Can I use a WiFi QR code for guests?

Yes. You can display the generated QR code in your home, office, restaurant, hotel, classroom or other suitable location.

Does AuraQR store my WiFi password?

The QR code is generated in your browser. AuraQR does not need to send your WiFi information to a server for QR generation.

Will every phone automatically connect?

QR scanning and automatic WiFi connection behavior depends on the device, operating system and security configuration.
