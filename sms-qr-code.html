Free SMS QR Code Generator

AuraQR lets you create an SMS QR code that stores a phone number and optional message. When scanned, compatible devices can open the SMS application with the information prepared.

How to Create an SMS QR Code

  1. Enter the phone number.
  2. Add an optional SMS message.
  3. Click Generate SMS QR Code.
  4. Scan the QR code with your phone.
  5. Check that the SMS application opens correctly.
  6. Download the QR code as a PNG image.

Where Can You Use an SMS QR Code?

SMS QR codes can be useful on posters, advertisements, business cards, product packaging, event materials, customer support materials and flyers.

SMS QR Code FAQ

What is an SMS QR code?

An SMS QR code contains an SMS link that can open a compatible messaging application with a phone number and optional message.

Is the SMS QR code free?

Yes. AuraQR provides free QR code generation directly in your browser.

Can I add a pre-filled message?

Yes. You can enter a message that will be included in the SMS link.

Does AuraQR send the SMS?

No. AuraQR only creates the QR code. Your phone's messaging application handles the actual SMS.
